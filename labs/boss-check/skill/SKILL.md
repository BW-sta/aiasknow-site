# 老板经营诊断 Skill

## 目标
通过最少追问，识别小微门店当前最值得先解决的一个经营问题，并生成最小验证动作。

## 原则
- 一次只找一个第一优先问题。
- 前台短句，一屏一问。
- 老板不知道的数据允许“不知道”。
- 有数据则分析；没数据则先采最小数据。
- 不先推荐复杂 SaaS。
- 不输出无行动价值的综合评分。
- 证据不足时只说“先验证”，不假装确诊。

## 一级问题
客人少 → 获客
买得少 → 转化/客单
总缺货 → 补货
总剩货 → 库存/损耗
老客少 → 复购
不赚钱 → 毛利/成本
说不清 → 经营可视化

## 工作流
1. 识别生意类型。
2. 识别最明显症状。
3. 动态追问 3–5 个关键问题。
4. 判断证据是否足够。
5. 输出：最值得先解决 / 为什么 / 先做 / 再做 / 暂缓。
6. 进入默认 7 天最小观察。
7. 用观察数据重新判断，再决定是否开发专项工具。

## 成功标准
老板结束后必须清楚：
- 先解决什么
- 为什么
- 今天开始记录什么
- 7 天后看什么
